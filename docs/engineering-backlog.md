# Engineering backlog

This backlog records findings outside the phase 1 documentation work. Sensitive
details and reproduction material must go in an ignored `local-notes/` file or
a private GitHub security advisory, not in this document.

| ID | Priority | Component | Finding | Recommended action | Status |
| --- | --- | --- | --- | --- | --- |

| ENG-005 | High | Administration | SSH remains exposed to one mutable public `/32` even though the host is SSM-managed. | Verify Session Manager access and emergency recovery, then remove routine SSH ingress through a reviewed Terraform change. | Open |
